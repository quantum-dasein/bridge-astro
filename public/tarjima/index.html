Субтитры прямо в Zoom
  1. Начните встречу в Zoom как организатор.
  2. Внизу у кнопки «Показать субтитры» нажмите стрелку → «Настроить ручного титровальщика» → «Копировать API token».
  3. Вставьте его сюда. Слушатели включают субтитры кнопкой CC в своём Zoom — второй экран не нужен.

Токен действует только в этой встрече — в новой скопируйте заново. В сессионных залах у каждого зала свой токен.

Введите ключ и нажмите «Начать».
