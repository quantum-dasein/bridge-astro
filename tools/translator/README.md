# Живой переводчик речи RU → UZ

Субтитры на узбекском в реальном времени для онлайн-занятий Академии.
Работает с Zoom, Google Meet, Telegram — с чем угодно: интеграция с
конференцией не нужна, участники просто открывают ссылку.

- **преподаватель** — https://www.bridgeconsult.uz/tarjima/ (Chrome)
- **слушатели** — https://www.bridgeconsult.uz/tarjima/view.html

## Как устроено

1. Речь распознаёт **сам браузер преподавателя** — Chrome, Web Speech API,
   русский, бесплатно. В Brave распознавание отключено.
2. Готовая фраза уходит в `api/tarjima/say.js` вместе с тремя предыдущими
   фразами и их переводами — ради связности. Функция переводит её через
   Claude и кладёт в Upstash Redis.
3. Слушатели раз в 2 секунды опрашивают `api/tarjima/feed.js`.

**Почему опрос, а не SSE.** Функции Vercel короткие, и каждый запрос попадает
в свой экземпляр: зритель, подключённый к одному, не увидит фразу, ушедшую в
другой. Лента отдаёт всем **один и тот же** ответ — последние 20 строк и
общий счётчик, без параметров в адресе, — поэтому CDN раздаёт его сам, а до
Redis доходит примерно один запрос в две секунды при любом размере группы.

## Словарь терминов

`src/data/fidicGlossary.mjs` — около 70 терминов FIDIC. Узбекское
соответствие каждого взято из узбекских текстов сайта (`src/data/academy.uz.ts`,
`offer.uz.ts`), где оно стоит на месте русского, — ни одного придуманного.
Термины находятся во фразе в любом падеже («уведомлении», «Инженерами») и
подсказываются модели только когда прозвучали.

Узбекские тексты сайта не вычитаны носителем-юристом, значит и словарь не
вычитан. **Его должна пройти глазами Лариса Константиновна.**

## Страница преподавателя

- **Очередь.** Фразы уходят строго по одной, иначе перевод короткой второй
  фразы мог бы прийти раньше длинной первой.
- **Длинный монолог режется сам.** Chrome закрывает фразу только на паузе;
  после 30 слов или 12 секунд без паузы страница закрывает её сама, чтобы
  субтитр не опаздывал на минуту. На стыке может потеряться слово.
- **Chrome сам обрывает распознавание** каждые несколько минут — страница
  поднимает его заново.
- **Экран не засыпает**, пока идёт распознавание.
- **«Новое занятие»** стирает пробы, сделанные перед эфиром.
- **«Экран для слушателей»** — QR-код и ссылка во весь экран, чтобы показать
  в Zoom через демонстрацию.
- Под кнопками — счётчик: сколько фраз, средняя задержка и **оценка**
  стоимости занятия.

## Страница слушателя

Переключатели запоминаются на телефоне: `rus` — русский оригинал под
переводом, `кирилл` — узбекский кириллицей (`public/tarjima/kirill.js`;
английские термины FIDIC остаются латиницей), `yirik` — крупный шрифт,
`avto` — автопрокрутка.

Если перевод не состоялся (нет денег на счёте, лимит, отказ модели),
слушатель видит русский оригинал, отчёркнутый и подписанный «Tarjima
ishlamadi — matn rus tilida». Молча выдать русский текст за узбекский на
занятии по контрактам нельзя.

## Сколько стоит

Оценка, не замер: у API пока нет денег, чтобы измерить на живой лекции.
Фраза — около 600 токенов на вход и сотни на выход. Двухчасовая лекция —
порядка 600–1000 фраз.

| модель | за фразу | за 2 часа |
|---|---|---|
| `claude-opus-5` (по умолчанию) | ≈ $0.005 | ≈ $3–6 |
| `claude-sonnet-5` | ≈ $0.002 | ≈ $1.5–2.5 |

Настоящую цифру покажет счётчик на странице преподавателя после первого
занятия. Upstash и Vercel укладываются в бесплатные тарифы.

## Переменные окружения Vercel

| | |
|---|---|
| `TARJIMA_KEY` | пароль преподавателя; без него `/api/tarjima/say` отвечает 500 |
| `ANTHROPIC_API_KEY` | ключ перевода; тот же, что у `api/chat.js` |
| `KV_REST_API_URL`, `KV_REST_API_TOKEN` | ставит интеграция Upstash; при другом префиксе имён хранилище находится само |
| `TARJIMA_MODEL` | необязательно; по умолчанию `claude-opus-5` |
| `TARJIMA_DAILY_LIMIT` | необязательно; фраз в сутки, по умолчанию 3000 — защита от утёкшего ключа |

## Локальная отладка

```bash
node tools/translator/server.mjs
```

Преподаватель — `http://localhost:8787/`, слушатели — `http://localhost:8787/view`.
Без `ANTHROPIC_API_KEY` или с `MOCK=1` модель не вызывается: фраза уходит
слушателям как есть, с пометкой. Это упрощённая версия с SSE — очереди,
контекста и кириллицы в ней нет.

## Чего здесь намеренно нет

**Озвучки узбекского голосом.** Технически можно, но узбекский синтез речи
слабый, а в юридическом обучении уверенно произнесённый неверный термин
хуже, чем его отсутствие: слушатель не видит, что перевод соврал. Субтитры
человек читает глазами и сверяет со слайдом.
