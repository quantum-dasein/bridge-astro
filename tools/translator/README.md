# Живой переводчик речи RU → UZ

Субтитры на узбекском в реальном времени для онлайн-занятий Академии.
Работает с Zoom, Google Meet, Telegram — с чем угодно: интеграция с
конференцией не нужна, участники просто открывают ссылку.

## Почему свой, а не Wordly

| | Wordly | этот |
|---|---|---|
| час эфира | ~$75 за поток | ~$1–2 |
| терминология FIDIC | общая модель | глоссарий Ларисы, 271 термин |
| узбекский | есть не везде | есть |

Глоссарий собран из её же материалов — пособия «Продвинутый
контракт-менеджмент» и узбекских версий сайта. Именно он и есть ценность:
в узбекском для половины понятий FIDIC нет устоявшегося юридического
словаря, и универсальный переводчик их выдумывает каждый раз заново.

## Запуск

```bash
node tools/translator/server.mjs
```

Открыть:

- **преподаватель** — `http://localhost:8787/` — Chrome, кнопка «Начать», говорить
- **слушатели** — `http://localhost:8787/view` — открывают на телефоне рядом с Zoom

Проверить тракт без ключа и без денег:

```bash
MOCK=1 node tools/translator/server.mjs
```

В режиме MOCK подставляются только термины глоссария — связка «речь →
сервер → субтитры» проверяется целиком, модель не вызывается.

## Переменные окружения

| | |
|---|---|
| `ANTHROPIC_API_KEY` | ключ для перевода |
| `TRANSLATOR_MODEL` | модель, по умолчанию `claude-sonnet-5` |
| `PORT` | порт, по умолчанию 8787 |
| `MOCK=1` | без модели, только глоссарий |

## Как устроено

1. Речь распознаёт **сам браузер преподавателя** — Chrome, Web Speech API,
   русский, бесплатно. Отдельный сервис распознавания не нужен, ключ тоже.
2. Готовые фразы уходят на сервер, тот переводит с глоссарием и раздаёт
   слушателям через Server-Sent Events.
3. В подсказку модели попадают только те термины, что реально встретились
   во фразе, — иначе задержка и цена растут на пустом месте.

Задержка: 2–4 секунды от сказанного до субтитра. Для лекции нормально.

## Что важно знать

- **Промежуточные результаты распознавания не переводятся.** Chrome
  переписывает фразу на лету, переводить каждую версию — жечь деньги.
  Отправляется только финал, после паузы.
- **Chrome сам обрывает распознавание** каждые несколько минут. Страница
  преподавателя поднимает его заново, иначе субтитры молча умрут посреди
  занятия.
- **Сбой API не гасит субтитры**: при ошибке фраза уходит через глоссарий,
  занятие продолжается.
- Говорить надо обычным темпом, **с паузами между мыслями** — по паузе
  браузер и решает, что фраза закончилась.

## На проде (Vercel)

Эта папка — для отладки на своей машине. Для занятия работает то, что
выложено на сайт:

- **преподаватель** — `https://www.bridgeconsult.uz/tarjima/`
- **слушатели** — `https://www.bridgeconsult.uz/tarjima/view.html`

Код: `api/tarjima/say.js`, `api/tarjima/feed.js`, страницы в `public/tarjima/`.
Глоссарий один на обе версии — `src/data/fidicGlossary.mjs`; он лежит вне
`api/`, потому что Vercel считает функцией каждый `.js` внутри `api/`.

**SSE там не живёт**: функции короткие, и каждый запрос попадает в свой
экземпляр — зритель, подключённый к одному, не увидит фразу, ушедшую в
другой. Поэтому фразы кладутся в Upstash Redis, а слушатели опрашивают
ленту раз в 2 секунды.

Лента отдаёт всем **один и тот же** ответ — последние 20 строк и общий
счётчик, без параметров в адресе. Одинаковый ответ означает один ключ
кэша, поэтому CDN раздаёт его слушателям сам, а до Redis доходит примерно
один запрос в две секунды независимо от размера группы. Лишнее зритель
отбрасывает у себя по номеру строки. Без этого поштучный опрос десятка
человек съедал бы бесплатный тариф Upstash за половину занятия.

Переменные окружения Vercel:

| | |
|---|---|
| `TARJIMA_KEY` | пароль преподавателя; без него `/api/tarjima/say` отвечает 500 |
| `ANTHROPIC_API_KEY` | уже стоит для `api/chat.js` |
| `KV_REST_API_URL`, `KV_REST_API_TOKEN` | ставит интеграция Upstash (Storage → Redis) |

Пока Redis не подключён, преподаватель перевод видит, а слушатели — нет:
страница преподавателя честно пишет об этом строкой «Хранилище: …».

## Чего здесь намеренно нет

**Озвучки узбекского голосом.** Технически можно, но узбекский синтез речи
слабый, а в юридическом обучении уверенно произнесённый неверный термин
хуже, чем его отсутствие: слушатель не видит, что перевод соврал. Субтитры
человек читает глазами и сверяет со слайдом.
